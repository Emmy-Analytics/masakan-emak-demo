MASAKAN EMAK — VERSI 2 (MENDEKATI REFERENSI)
================================================
Fitur:
- Header kaca/transparan membulat, logo script, sapaan, navigasi, pencarian, tombol Pesanan.
- Grid 4 x 2 kartu putih dengan foto makanan bulat, harga, ikon tas oranye.
- Responsif untuk layar kecil.
- Pencarian menu.
- Tombol tas menambahkan menu ke Pesanan Saya.
- Ringkasan pesanan dan tombol WhatsApp.

JALANKAN:
1. Ekstrak ZIP.
2. Buka index.html di browser.
3. Edit script.js untuk mengganti WHATSAPP_NUMBER dengan nomor WhatsApp yang benar.
4. Ganti data demo (nama, harga, foto, alamat) sebelum digunakan klien.

Catatan:
- Nama dan harga hanya contoh.
- Nomor WhatsApp default hanya placeholder.
- Belum ada login asli, database, atau payment gateway.
- Foto makanan dalam folder images diambil dari mockup visual AI untuk demo.
