# Masakan Emak — Website Demo

A restaurant website concept built to showcase menu browsing, interactive ordering, and a responsive visual interface.

## Features

- Responsive layout for desktop and mobile
- Menu grid with food images and prices
- Menu search and category filters
- Interactive shopping cart
- Order summary and total price calculation
- WhatsApp order integration for the demo

## Technologies

- HTML
- CSS
- JavaScript
- AI-assisted website development and visual design

## Live Demo

[Open Masakan Emak](https://emmy-analytics.github.io/masakan-emak-demo/)

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser, or use VS Code with Live Server.
3. Review `script.js` and update the WhatsApp number before testing the ordering flow.
4. Replace demo menu names, prices, images, and restaurant details with verified information before real-world use.

## Project Notes

- This is a portfolio demonstration, not an official restaurant website.
- Menu items, prices, and restaurant information may be examples.
- The WhatsApp ordering flow requires a valid restaurant number.
- No authentication, database, or payment gateway is currently included.
